# Law Firm Management System with CMS
**Full-stack Web Application | [Live website link](https://shamiul-islam-and-associates.vercel.app/)**

- **Core Tech:** React 19, TypeScript, Redux Toolkit, Vite, Tailwind CSS, Clerk Auth.
- **Admin Features:** Tiptap Editor, Cloudinary, React Hook Form, Zod.

    
### Key Contributions & Features:
- **Advanced Content Management (CMS):** Designed and implemented a robust admin dashboard allowing non-technical staff to publish legal blogs, manage team associate profiles, and update firm services in real-time.
- **Rich Text Editorial Workflow:** Integrated Tiptap Editor with customized extensions to enable seamless blog creation, featuring automated image compression via browser-image-compression and secure Cloudinary uploads.
- **Secure Authentication:** Integrated Clerk for multi-role authentication, ensuring secure access to the administrative panel and protecting sensitive firm data.
- **State Management & Validation:** Leveraged Redux Toolkit for efficient global state management and implemented rigorous client-side schema validation using Zod and React Hook Form.
- **Performance & UI/UX:** Developed a high-performance, responsive interface using Tailwind CSS v4 and Radix UI primitives, achieving smooth navigation with Framer Motion and React Router v7.
- **Production Readiness:** Implemented security best practices like DOMPurify for XSS protection and integrated Facebook Pixel for marketing analytics and WhatsApp for client engagement.
